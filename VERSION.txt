### 0.6.1 (2026-06-27)
- **Media disk replaced: failing HDD → SSD.** Swapped the failing Seagate ST1000LM037 exFAT HDD at `/mnt/usb` for a **Crucial BX500 1 TB SSD** (ext4, label `media`, mounted **by UUID** with `nofail` so a missing disk can't hang the remote Pi's boot). Done live over the WireGuard tunnel; verified clean across a reboot (`findmnt` = SSD, all services up, `/api/health` ok, `get_throttled` back to `0x0`).
- **Media not migrated — re-encode from source.** The `home/` library tree was recreated empty (`media-reindex.py` → catalog 0/0); the user's `movies/`+`tv/` were preserved on the SSD. Durable read-models (`catalog.json`, trips, fuel, waypoints, view-state, GPS tracks) untouched on the SD card. The map tile cache (`/mnt/usb/home/maptiles`) starts empty — re-seed with `map-preseed.py` before a trip.
- **Power note:** running both disks on the Pi's USB bus during the swap caused a single ~4 s under-voltage dip; a single SSD boots clean at `0x0`. The 12 V→5 V feed is still the underlying fix (`subsystems/power/`).
- **Docs + skill sweep:** retired every "failing exFAT HDD / bad-sector" reference across the repo (code comments, `configs/`, `docs/`, `subsystems/`, `mapoptimize.md`) to the new ext4 SSD; kept `subsystems/media/hdd-failure-2026-06-26.md` as a RESOLVED historical record; refreshed the `sallynet-pi-ops` skill (SSD facts + the layered-map render pipeline + `view-state.json` read-model).

### 0.6.0 (2026-06-27)
- **Map interface — layered on-demand PNG + shared web control (built, TDD'd; 94 tests green).** Extends the P1–P5 ambient map per `mapoptimize.md`. All **additive** to the frozen `/api` contract (no `schemaVersion` bump). The PNG is generated on demand per `/api/map.png` (single-flight cached), tuned for highway/city driving — not streamed.
- **Shared view-state:** new `view-state.json` + `GET/POST /api/view`. `/api/map.png` with no `?layers=` now renders the shared layer set, so a toggle on the `/map` page persists server-side and **every browser + the Roku glass converge** — zero Roku edits (it already sends no `layers`). `/map` rewritten to load/POST `/api/view`.
- **GPS-loss safety overlay:** an always-on banner baked onto the PNG once a fix is missing past `SALLY_GPS_ALERT_AFTER_S`; the map **freezes at the last-known position** instead of teleporting home; also surfaced on every Roku screen via `/api/state.alerts` (`gps_lost`) + a new `nav` block. Backed by a new always-on `nav-tick` daemon (`scripts/nav-tick.py` + `navstate.py`, gpsd-direct, SD-sparing write-gate) so loss is detected even when nobody polls.
- **Photo POIs:** past-trip geotagged photos surface as camera pins near the current position — new `photos` layer; `photo-poi.json` built by `media-reindex.py` (piggybacked on the catalog rebuild, no new timer); POI-style declutter + a hard `PHOTO_POI_MAX_KM` great-circle cull.
- **Favourites:** a `favourite` flag on the existing `waypoints.json` (manual decimal lat/lon entry on `/waypoints`, gold-star markers), **excluded from the route** by a one-line `select_next_waypoint` filter that covers both the map's "next" and the arrival auto-advance; `op=promote` turns a favourite into a route stop.
- **Tile-fetch hardening (good-citizen throttle):** negative cache + global circuit breaker + 429/Retry-After honoring + tighter timeout + a `throttled` status chip, all in `tiles.py`.
- **⚠️ Vendor-compliance correction:** documented that Thunderforest's *free* Hobby/Solo tiers FORBID the server-side caching + pre-seed this design relies on (Small Business+ / custom plan required — being arranged); corrected `mapoptimize.md`, `map-navigation-brainstorm.md`, and code comments. Satellite (EOX Sentinel-2 cloudless) deferred, but the `baseSource` hook is reserved.
- New unit `configs/telemetry/nav-tick.service` (a `Type=simple` daemon, not a timer); `deploy-media-worker.sh` ships + enables it. New test modules: `test_view`, `test_navstate`, `test_maproute`, `test_waypoints_api`, `test_photopoi` (+ extensions to `test_tiles`/`test_mapgen`/`test_waypoints`).

HDD tree `/mnt/usb/home/`.
